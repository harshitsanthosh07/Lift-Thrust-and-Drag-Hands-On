What is thrust?

Thrust is the force that drives objects forward and causes them to accelerate. This force has to oppose drag in order to accelerate.

What happens if thrust is equivalent to drag?

The object will move at a constant rate. If thrust and drag were a net force of 0N, the object will not move. If both were 50N, the object will countinue travelling at the same speed as it was travelling before the forces were balanced. Note that if forces are balanced -but the object is still in motion- it is not considered acceleration.
